## 当前开发状态
本轮已实现：双人最多三局、先赢两局；三至四人三轮积分赛；平局与并列积分；每轮轮换出生位置；所有玩家验证并准备后进入三秒倒计时；首轮不限时、局间五分钟提醒，时间到不会强制开战。

保留原有功能：真实 Python / JavaScript、单人训练、三角色采集/攻击/卸货/重生、热部署失败保留旧版、手册按需查阅、暂停和重置训练、代码下载、本机草稿、云端房间和刷新恢复。

## 已知限制与后续目标
这是客户端运行代码的休闲对战。没有服务端 Python 沙箱、严格反作弊、排位、账号、战争迷雾、队伍模式或完整持久回放；不声称实现这些能力。
离线时只保留最后动作，程序不会继续决策；刷新需重新运行。准备阶段离线超过 15 秒会取消准备；没有踢人/转移房主，永久离开的玩家需要大家新建房间。房间沿用创建一小时过期规则，准备不限时指没有强制开战倒计时。
三轮四人赛每人只访问四个位置中的三个，不能完全消除位置优势。三人可轮遍三处出生点。相同策略仍可能因到达资源时间和竞争产生不同结果。
约 400ms HTTP 同步、250ms 决策和 Canvas 插值，不等于 WebSocket 或生产延迟保证。尚未做公开并发压测，长时间所有客户端离线的模拟也不会逐步完整补算。
后续优先收集朋友试玩反馈：离线席位处理、地图镜像、完整回放及同步负载；可信服务端执行单独设计，不与本轮简单多人玩法混在一起。
